# R45: orientation-aware consequence deployment

R45 is a narrow consumed-development component test.  It replaces the R30
consequence ensemble used by R39 with the reward-free R43
orientation-factorized ensemble.  The recorded graph, landmark destinations,
mobility model, empirical passage geometry, executor, hidden-goal observation
model, acquisition objective, return objective, task panel, and episode budget
remain frozen.

The R43 model was trained without hidden goals or task reward.  Its spatial
head is copied from R30; only endpoint posture is reparameterized so that
physical orientation uncertainty can represent a possible flip.  Therefore
R45 reuses the frozen spatial graph and recomputes only quantities that depend
on samples of the full predicted endpoint state:

1. model-bridge connection weights; and
2. live-state candidate values evaluated during the gate.

The R31 mobility model is deliberately not retrained.  R44 already established
that it assigns lower continuation to physically inverted samples generated by
R43.  This test asks whether exposing that posture risk in the deployed
consequence distribution avoids the task-3 flip and improves the same R39
two-goal gate.

The two goals are consumed development tasks 3 and 5.  This is not confirmation
evidence, does not access the sealed panel, and cannot support a full-method
claim.
