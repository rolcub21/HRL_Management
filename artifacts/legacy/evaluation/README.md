# Legacy evaluation artifacts

These small files were already tracked in the historical repository and are
retained for provenance. They are smoke tests and debugging outputs, not the
source of the current paper results.

- `common_eval_20260623-142857.csv`: 15 historical PSLAP evaluation rows.
- `common_eval_20260623-143142.csv`: one historical HRL evaluation row.
- `evaluation_smoke.csv` and `evaluation_smoke_gpu.csv`: duplicate HRL smoke
  evaluations on two execution environments.
- `ga_smoke.csv`: one GA-assisted smoke evaluation.
- `hrl_old_arch_smoke.csv`: one failed old-architecture HRL evaluation.
- `debug_store_events.csv`: a small storage-event debugging trace.
- `return_over_time.png`: a legacy training-return plot.

Current experiment outputs, checkpoints, tables, GIFs, and MP4s live under
`results/` and are intentionally excluded from Git.
