# Experiment programs

New experiments are organized by method family and ordered identifiers.

| Program | Contents |
|---|---|
| [`conditioned_vcg/`](conditioned_vcg/) | E1 benchmark; E3--E5 method ablations; E11 distribution shift; E12 representation attribution; E14 exact-certificate reuse; and separate D-series development history |
| [`robust_vcg/`](robust_vcg/) | separate robust-certification extension |

The older flat directories are frozen compatibility locations. Completed
contracts and result manifests refer to those exact paths, so they are not
renamed or replaced. The numbered directories provide the canonical human
entry points and delegate to the frozen launchers.
