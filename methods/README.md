# Methods

This directory contains the public entry points and paper-facing descriptions
of active methods.

| Package | Status | Experiment program |
|---|---|---|
| [`conditioned_vcg/`](conditioned_vcg/) | current final VCG method | [`experiments/conditioned_vcg/`](../experiments/conditioned_vcg/) |

Older root-level modules are retained because completed experiment contracts
bind their exact paths and file hashes. Public imports should use the package
above; new method versions should be added here rather than creating another
unindexed root module.
